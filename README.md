# BlueStacks Macro Pro (Mac Edition)

macOS 환경에서 블루스택(BlueStacks) 앱 플레이어를 제어하기 위한 지능형 이미지 인식 매크로 프로그램입니다.
Python, Tkinter, PyAutoGUI, OpenCV를 사용하여 개발되었습니다.

## ✨ 주요 기능

*   **이미지 인식 기반:** 좌표가 아닌 이미지를 인식하여 클릭하므로 창 위치를 옮겨도 작동합니다.
*   **두 가지 실행 모드:**
    *   **순차 실행:** 1번 -> 2번 -> 3번 순서를 지키며 실행합니다.
    *   **발견 즉시 실행:** 순서에 상관없이 화면에 보이는 버튼을 즉시 클릭합니다.
*   **트리 구조 시퀀스:** 동작을 그룹화하고, 특정 조건(감시자)이 만족될 때만 하위 동작을 실행하는 복잡한 로직 구현이 가능합니다.
*   **에러 자동 복구:** 게임 중 발생하는 팝업이나 에러창을 백그라운드에서 감시하고 자동으로 처리합니다.
*   **Retina 디스플레이 지원:** 맥북의 고해상도 화면에서도 정확한 좌표를 찾아 클릭합니다.
*   **쿨타임 관리:** 스킬이나 아이템 사용 시 재사용 대기시간을 설정할 수 있습니다.

## 🚀 설치 및 실행 방법

### 1. 실행 (간편 방법)
`BlueStacksMacro.app` 아이콘을 더블 클릭하여 실행합니다.

### 2. 실행 (터미널)
```bash
./run_macro.sh
```

## 📖 사용 가이드

### 1. 기본 동작 추가
1.  상단에서 **대상 앱(BlueStacks)**을 선택합니다.
2.  **"➕ 루트 동작 추가"** 버튼을 누릅니다.
3.  **"캡처"** 버튼을 누르고 화면의 버튼 영역을 드래그합니다.
4.  동작 이름과 대기 시간(클릭 후 딜레이)을 입력하고 **확인**을 누릅니다.

### 2. 감시자(Watcher) 활용 (분기 처리)
특정 상황에서만 다른 행동을 해야 한다면 감시자를 사용하세요.
1.  **"➕ 루트 동작 추가"**를 누르고 타입을 **"감시자 (Watcher)"**로 선택합니다.
2.  감시자가 될 이미지(예: "전투 종료" 화면)를 캡처합니다.
3.  리스트에서 방금 만든 감시자를 선택하고 **"↳ 하위 동작 추가"**를 누릅니다.
4.  "확인 버튼 클릭", "나가기 클릭" 등 하위 동작을 추가합니다.
-> **효과:** 평소엔 지나치다가, "전투 종료" 화면이 뜨면 하위 동작들을 실행합니다.

### 3. 에러 처리 (백그라운드 감시)
갑자기 뜨는 네트워크 오류나 광고창을 처리합니다.
1.  상단의 **"⚙️ 에러 감시 설정"** 버튼을 누릅니다.
2.  **"➕ 캡처하여 추가"**를 눌러 에러 팝업의 "X" 버튼이나 "확인" 버튼을 등록합니다.
3.  매크로가 도는 동안 주기적으로(기본 10초) 화면을 검사하여 에러창이 뜨면 즉시 처리합니다.

### 4. 쿨타임 설정
리스트에서 동작을 더블클릭하거나 **"✏️ 선택 편집"**을 눌러 **쿨타임**을 설정하세요.
해당 시간 동안은 이미지가 보여도 다시 클릭하지 않습니다.

## ⚠️ 주의사항
*   **창 크기:** 블루스택 창의 크기를 조절하면 이미지를 다시 캡처해야 합니다. (위치 이동은 OK)
*   **화면 캡처 권한:** 처음 실행 시 화면 기록 권한을 요청하면 허용해 주세요.
*   **비상 종료:** 매크로 실행 중 **`ESC`** 키를 누르면 즉시 멈춥니다.
